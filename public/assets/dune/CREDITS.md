# Dune Glide — scenery art

**Background Elements Remastered** by Kenney (https://www.kenney.nl),
released under Creative Commons Zero (CC0 1.0). See `LICENSE.txt`.

- `sprites/` — the pack's `PNG/Retina` sprites (2x): sun, moons, clouds,
  cacti, palm, dead tree, bushes, pyramids, towers, castle ruins.
- `bg/` — the pack's `Backgrounds/Elements` tileable layers (mountains,
  hills). They are single-colour silhouettes; the game re-tints them from the
  day/night palette (see `src/game/render/art.ts`).

Only the pieces the game uses are included.
